# V9968 Board Rev2 Case

HRA氏のV9968ボードRev2に対応した、ネジレス設計の3Dプリント用ケースです。上蓋（Top）と底ケース（Bottom）のモデルを公開しています。

## ダウンロード

| 部品 | STL | 3MF |
| --- | --- | --- |
| 上蓋 | [Top.stl](STL/V9968_Board_Rev2_Case_Top.stl) | [Top.3mf](3MF/V9968_Board_Rev2_Case_Top.3mf) |
| 底ケース | [Bottom.stl](STL/V9968_Board_Rev2_Case_Bottom.stl) | [Bottom.3mf](3MF/V9968_Board_Rev2_Case_Bottom.3mf) |

単位はmmです。STLを読み込む際もmmとして扱ってください。

3MFはFreeCADから出力した形状モデルです。Bambu Studioの印刷設定、材料設定、プリンター設定、G-codeは含まれていません。

## 印刷と組み立て

お使いのスライサーにモデルを読み込み、プリンター・材料に合わせて配置と印刷設定を調整してください。上蓋と底ケースの固定にネジを使用しない設計です。

プリンターや材料、印刷条件によって寸法やはめ合わせが変わります。基板を組み込む前に、干渉やはめ合わせを確認し、無理な力を加えないでください。

本リポジトリでは、特定のプリンター・材料・印刷条件における検証結果は掲載していません。
